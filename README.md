
# BookBot

A command-line book analysis tool built with Python.

## Features

- Read text files
- Count total words
- Count character frequency
- Sort characters by frequency
- Generate a formatted report
- Accept book paths through command-line arguments

## Usage

```bash
python3 main.py books/frankenstein.txt
